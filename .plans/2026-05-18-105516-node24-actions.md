# Node 24 GitHub Actions Plan

## Goal

Remove GitHub's Node 20 action-runtime warning from CI and release workflows by updating first-party checkout actions to the current Node 24-compatible major version.

## Approach

- Update workflow files under `.github/workflows`.
- Change `actions/checkout@v4` to `actions/checkout@v6`.
- Run the repository verification gate.
- Commit and push a PR branch.
- Verify GitHub CI.

- `.github/workflows/ci.yml`
- `.github/workflows/release.yml`
